# Bi2Te3 Case-Study Dataset Literature Sources

The carrier-mobility dataset included with this repository is the Bi2Te3-based
case-study dataset used to demonstrate the general workflow. It was compiled from
published literature. The table below documents the bibliographic sources for
this included dataset; it does not define the material scope of the framework.
